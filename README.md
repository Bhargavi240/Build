# BuildStock - Inventory & Sales Management

A modern, responsive web application for managing inventory, tracking stock, and processing sales transactions.

## Features
- Real-time inventory tracking and stock alerts
- Sales transaction and order processing
- Intuitive, modern UI built with React & Vite
- Fast and responsive performance

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Bhargavi240/build-stock.git
   ```
2. Navigate to the project directory:
   ```bash
   cd build-stock
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## Tech Stack
- **React**
- **Vite**
- **Lucide React** (Icons)
